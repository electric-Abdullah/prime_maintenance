## 🚀 Deployment Instructions (Render.com)

1. **GitHub Setup**: 
   - Initialize git: `git init`
   - Add files: `git add .`
   - Commit: `git commit -m "Initial commit"`
   - Push to GitHub.
2. **Render Setup**:
   - Connect GitHub repo.
   - Environment: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
3. **Environment Variables**:
   - `SUPABASE_URL`
   - `SUPABASE_KEY`
   - `GOOGLE_SHEET_ID`
   - `PORT` (default 3000)
